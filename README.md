# ExtractExpertSystem 🧪

Система поддержки принятия решений (СППР) для процесса сульфатизации.

## Основные функции
* **Интеллектуальный поиск:** Алгоритм подбора эталонной партии из базы знаний на основе массы ($\pm 5\%$) и химического состава (не менее 4 совпадений из 7 элементов).
* **Визуализация:** Интерактивная универсальная мнемосхема с динамическими индикаторами.
* **Прогнозирование:** Расчет ожидаемого извлечения/качества на основе исторических данных.
* **Рекомендации:** Построение графика целевой величины.

## Технологии
* **Python 3.10+**
* **PyQt5** — графический интерфейс.
* **SQLite3** — база знаний.
* **Matplotlib/PyQtGraph** — аналитические графики.

## Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите `main.py`.
